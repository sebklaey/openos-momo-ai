OpenOS System

openos.benz/system

Das Installationszentrale von OpenOS Momo AI — ein System für jedes Gerät. Erkannt: …. Installiere OpenOS als App mit eigenem Icon, als Vollbild-PWA auf dem Telefon — oder als zukünftiges Betriebssystem-Image für deinen Rechner. Alles von openos.benz, alles aus unserem eigenen IPFS-Stand.

1 · Installieren

iPhone / iPad empfohlen

Apple sperrt fremde Betriebssysteme — die stärkste Form auf iOS ist die installierte Web-App: Vollbild, eigenes Icon, offline fähig.

  1. Diese Seite in Safari öffnen
  2. Teilen-Knopf antippen (Vierkasten mit Pfeil)
  3. „Zum Home-Bildschirm" wählen → „Hinzufügen"
  4. Fertig: OpenOS startet wie eine eigene App

Android empfohlen

OpenOS als App (APK) mit Telefonie-Integration und OldNet Browser — plus der langfristige Weg: OpenOS als eigene System-ROM.

  1. APK von openos.benz/system/openos.apk laden (erscheint mit Stufe 2)
  2. Installation erlauben („Unbekannte Quellen")
  3. OpenOS starten — Telefon & Browser integriert
Bis dahin: „Zum Startbildschirm hinzufügen" im Browser-Menü installiert OpenOS als Vollbild-App — und das Telefon-Modul ist bereits fertig: Wählblock, Kontakte und Anrufprotokoll in der App (Account-Menü → Telefon). OpenOS kann sich auf Android sogar als Standard-Wähler für tel:-Links registrieren.

Computer Windows · macOS · Linux

Stufe 1: OpenOS als Desktop-App (Vollbild-Fenster, eigener Start). Fernziel: bootbares OpenOS-Live-System — dein Rechner wird das Gerät.

  1. Desktop-App (Tauri) von dieser Seite laden (erscheint mit Stufe 1b)
  2. Öffnen — OpenOS läuft als eigenes Programm
  3. Fernziel: OpenOS-System-Image brennen & booten
